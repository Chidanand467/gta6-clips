GTA6 Clipper – Privacy Policy

Effective date: 25 November 2026

This Privacy Policy explains how GTA6 Clipper ("the app", "we"), developed by GitHub user chidanand467, accesses, uses, stores, shares, protects and deletes Google user data. GTA6 Clipper is a personal automation tool that uploads permission-cleared gaming highlight clips to its owner's own YouTube channel. A description of the app is on the home page.

1. Google user data we access

When the channel owner signs in with Google, the app requests a single OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload – permission to upload videos to the signed-in user's YouTube channel.

Through this permission the app receives:

  • An OAuth access token and refresh token that let it upload videos on the user's behalf.
  • The YouTube video ID that YouTube returns after each upload.

The app does not access the user's name, email address, contacts, Gmail, Drive, YouTube watch history, comments, subscribers, analytics or any other Google data.

2. How we use Google user data

  • The OAuth tokens are used only to upload short video clips, with their title, description, tags and scheduled publish time, to the signed-in user's own YouTube channel.
  • The returned video IDs are used only to keep a record of what has already been uploaded, so the same clip is never uploaded twice.

Google user data is used only to provide this user-facing upload feature. It is not used for advertising, sold, used to build user profiles or databases, or used to develop, improve or train any artificial intelligence or machine-learning model.

3. Sharing, transfer and disclosure

We do not sell, rent, share, transfer or disclose Google user data to any third party, except:

  • Google/YouTube – videos and their metadata are sent to the YouTube Data API in order to upload them, which is the purpose of the app.
  • GitHub – the OAuth refresh token is stored as an encrypted secret in the owner's GitHub account so the scheduled upload job can run. GitHub acts only as a hosting provider and cannot use the token for its own purposes.
  • Where required by law.

AI text service: to suggest video titles, the app may send the spoken transcript of a clip (taken from a public, permission-cleared game stream) to an AI text service such as Google Gemini. This transcript is not Google user data. No OAuth tokens, account information or other Google user data are ever sent to any AI service.

4. How we store and protect data

  • OAuth credentials are stored only as encrypted secrets (GitHub Actions secrets), never in source code, logs or public files.
  • All communication with Google APIs uses HTTPS (TLS encryption).
  • Access is limited to the single channel owner. Credentials are never shared.
  • Only the minimum permission needed (upload only) is requested.

5. Data retention and deletion

DataHow long it's kept
OAuth refresh tokenUntil the user revokes access or the owner deletes the GitHub secret.
Short-lived access tokenIn memory only during an upload run (about one hour at most); never saved.
Uploaded video IDsIn a small private state file for as long as the app is in use; deleted when the app is shut down.
Temporary video filesDeleted automatically right after each upload.

How to delete your data: revoke GTA6 Clipper's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. You can also email us (below) to ask for deletion of all stored data; it will be deleted within 7 days. Videos already uploaded can be deleted in YouTube Studio.

6. Google API Services User Data Policy

GTA6 Clipper's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

7. YouTube API Services

GTA6 Clipper uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

8. Children

The app is not directed at children and does not knowingly collect data from anyone under 13.

9. Changes to this policy

If the way the app uses Google user data changes, this page will be updated and the effective date above will change before the new use begins.
